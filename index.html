Personal project

Second Memory

September 2026 – Present

Goal: replace scattered notes apps and spreadsheets with one offline-first place to track books, recipes, to-dos, a shopping list, and a household budget.

What I built: a multi-collection app (books with a yearly reading goal, recipes with scaling and a cook mode, repeating to-dos, a pay-period budget, a journal, and more) with search, filtering, sorting, and undo/redo across every collection, plus a small Python sync server I wrote (with conflict handling that never silently discards an edit, and daily backups) so data stays in step between my phone and computer. TripNest

October 2026

Goal: plan a whole trip in one place (itinerary, reservations, packing, and shared expenses) on a phone, offline, with no account and no server holding anyone's travel details.

What I built: an offline-first trip planner with an itinerary that shows each time in the place's own time zone, reservations and packing lists, shared expenses that always split to the exact cent and show who owes whom, maps, a printable booklet, backups, and a merge that combines an updated trip file from a second phone without losing edits.

Personal project

StoryVault

October 2026

Goal: give a novel-length manuscript a private writing studio that keeps the writing as plain files on my own computer, with no accounts and no subscription.

What I built: a local-first writing studio that imports a manuscript (Word, Markdown, text, ODT, or EPUB), splits it into chapters, and checks every import word for word. It adds an editor with proofreading and continuity checks, a story bible, exports to Word, PDF, EPUB, and more, verified backups with automatic recovery points, and an offline phone version with file-based sync.

Stack: React, TypeScript, TipTap, and a small Node server for local files, with more than 140 automated tests. Private repository (code walkthrough on request).

Personal project

MTG Collection Tracker

October 2026

Goal: know where every card in a physical Magic: The Gathering collection is stored and what the whole collection is worth, from a phone.

What I built: a self-hosted app that searches any card printing through the Scryfall API, then stores cards by box, binder, or deck. It keeps cached market prices with retry and stale-price handling, tracks value history, runs a want list with price alerts, suggests deck upgrades using only cards I already own, and takes weekly backups.

Stack: Next.js, React, TypeScript, and libSQL (SQLite locally, Turso hosted) on Vercel with a daily scheduled job. Installable PWA with over 100 automated tests, including fuzz tests and every API route called with hostile input. Private repository (code walkthrough on request).

Personal project

Our Family Budget

September – October 2026

Goal: give my family a household budget they can actually read and update, with big text and big buttons, that works offline and shows everyone the same numbers.

What I built: a spreadsheet-like budget with bills due soon and one-tap Mark Paid, a pay-period view, regular paychecks, savings goals, debts with a debt-free date estimate, month-by-month comparisons, undo, and CSV export. Devices stay in step through a private GitHub repository that holds one data file, so there is no server and no accounts. The public app itself holds no budget data.

Stack: HTML, CSS, JavaScript with no framework, a service worker for offline use, and the GitHub API. Hosted on GitHub Pages. The live site opens to a setup screen because the numbers live in a separate private repository.
