Case study

Sagebrush Sites

A hand-coded, mobile-first website and web-studio brand for salons and beauty businesses, taken from positioning through a live deployment on a custom domain.

Role
Designer & developer
Timeline
September 2026
Type
Personal project
Stack
HTML, CSS, JavaScript

View Live Site → View Code on GitHub →

The goal

Salons, barbers, nail studios, and spas depend on their website to turn a search or an Instagram click into a booked appointment. I wanted to launch a small web-studio brand aimed at that audience, and to build the site that sells the service as proof that I can deliver it.

What I built

  • A six-page studio site. Home, Work, Process, About, Skills, and Contact, written by hand in semantic HTML, responsive CSS, and vanilla JavaScript.
  • Four concept projects. Each is a standalone live demo site with its own layout idea: Haven Hair Studio (masonry gallery), Bloom Nail Studio (bento-style gallery and pill-chip service menu), Ironclad Barber Co. (dotted-leader price ledger and scroll-snap filmstrip), and Still Water Spa (story-style sections and a calm sage palette), each with a written case study.
  • A clear four-step process. Discover, Design, Build, Launch, with a promise of a clear quote before any work starts.
  • Booking-platform awareness. The site speaks to linking or embedding the tools these businesses already use, such as Vagaro, Square, Fresha, and Booksy.

Decisions that mattered

  • No frameworks. Hand-coded pages load fast and are easy to hand off to a small-business owner who just needs to edit text.
  • Mobile-first layouts. Customers often look up a salon and book from their phone, so every page is designed at phone width first.
  • Honest labelling. The Work page states plainly that the four projects are self-directed concept builds, not paid client work.
  • A real brand identity, not stock imagery. The site carries a real brand logo, and the About page uses a monogram rather than a stock photo that would misrepresent a real person.
  • A custom domain on free hosting. The site is served from GitHub Pages behind its own domain, so there is no hosting bill and no vendor lock-in.

What shipped

The site is live at sagebrushsites.com, with six pages and four working concept sites, all hand-coded with no external dependencies.

Skills this project shows

  • Semantic, accessible HTML and responsive, mobile-first CSS
  • Vanilla JavaScript for interactive UI without framework overhead
  • Translating a business goal (more bookings) into a site structure and process
  • Deploying a site end to end: repository, hosting, DNS, and custom domain
